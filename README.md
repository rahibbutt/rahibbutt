## ETL Pokepipeline production-ready project
A full‑stack solution that integrates:  
- **Vue.js 3 + Tailwind** for frontend application
- **NodeJS + Express** typescript for backend
- **Docker** for production-ready build
- **CI/CD** Github actions
- **Semantic** for version controlling
- **ESLint, Prettier, Jest** (for code quality and testing)
- **PM2** process manager (automatic application monitoring)
    
- **Pokepipeline Frontend**: [Pokepipeline Frontend](https://github.com/rahibbutt/pokepipeline-frontend)
- **Pokepipeline Backend**: [Pokepipeline Backend](https://github.com/rahibbutt/pokepipeline-backend)

## Demonstration Factory for Business Process Automation using Camunda 8 BPMS
A full‑stack solution that integrates:

- **Fischertechnik** robotics for warehouse operations  
- **IoT** for real-time production monitoring 
- **Docker** containers for microservices
- **Project** available here: [Business Process Automation Lab](https://github.com//BpaLabTHCologne/bpa_lab_demonstration_factory)
